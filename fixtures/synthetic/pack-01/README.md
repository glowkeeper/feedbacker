# Synthetic fixture pack 01

**Everything in this pack is fictional. It contains no real data.**

It contains no real student work, marks, comments, names, identifiers,
organisations, or assessment material. Every person, student number, and
organisation was invented for testing, and emails and URLs use reserved
example domains (RFC 2606). Any resemblance to real people or work is
coincidental.

Never add real material here or anywhere else in the repository (see
[`docs/data-handling.md`](../../../docs/data-handling.md)).

## Contents

| File | Purpose |
| --- | --- |
| `rubric.json` | A fictional four-criterion rubric in the points-based style of Turnitin and Canvas rubrics: nine levels per criterion, each with one points value and a classification label. One label is deliberately inconsistent with its points (`2:2 (68)` under *Testing*), because real rubrics contain such slips and importers must keep labels exactly as written. |
| `submissions/` | Four fictional coursework reports: two docx, two pdf, of varying quality. |
| `original-assessments.json` | Fictional original marks as they would be imported from a Turnitin "current view": points, raw labels and scores, summary comments, and inline comments anchored to passages. `sub-b` is marked generously on purpose, so moderation has something to find. |
| `seeded-identifiers.json` | The fictional identifiers planted in each report, including document metadata, for anonymisation tests (#16). |
| `moderation-record.example.json` | A small valid moderation record with module context, an open review of `sub-a` (original marks visible throughout), a blind review of `sub-b` (judged first, revealed, one criterion revised), and a verdict for each. |

The seeded identifiers include both direct identifiers (names, student numbers,
emails, URLs) and indirect ones (fictional employers, a first-name mention,
author metadata), because both matter for anonymisation.

## Regenerating

The pack is generated by code and is reproducible:

```sh
cd core
uv run --group fixtures python scripts/make_fixtures.py
```
