# Claude Code Guide

Read and follow [`AGENTS.md`](./AGENTS.md) before working in this repository. It is the canonical project and engineering guide and applies to all changes.

In particular, treat Feedbacker as a workflow, governance, and assessment layer around AI—not merely a feedback generator. Keep educators in control of marks and released feedback, preserve traceability, and treat all assessment material as sensitive educational data.

If this file and `AGENTS.md` ever appear to conflict, `AGENTS.md` takes precedence. Update the canonical guide rather than duplicating evolving instructions here.
