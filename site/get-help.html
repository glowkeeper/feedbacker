Help

Get help.

Feedbacker is made and supported by one person, so a reply can take a few days. Here is how to get unstuck, and how to tell me what would make it easier to start.

Stuck on setup, or not comfortable with a terminal?

Setting up means a few steps in a terminal. If that is what is stopping you, tell me, on the help form or by email (below). It helps me see whether an installer is wanted, and I may be able to help you through it. Say what you are trying to do and where you stopped.

If you look after other people's computers, the setup guide is the whole of it, and the page for institutions says what an institution needs to decide.

Using it

The user guide takes you through a moderation, and through marking a cohort, step by step. See it in use shows the same screens with made-up coursework, without installing anything.

Prefer email, or not on GitHub?

Write to steve@huckle.studio. One person reads it, so a reply can take a few days. The same rule applies as for issues: never send students' work, marks, names or other personal data, and never your API key.

Something isn't working

Open an issue with the help form or a bug report from the list of forms. You need a free GitHub account.

Never put students' work, marks, names or other personal data in an issue, and never your API key. Describe the problem, or show it with the made-up coursework that comes with Feedbacker.

A security problem

Please don't open a public issue. Report it privately: the security policy says how.

Ideas, and what would make you start

A correction, an idea, or "I would use it if…" are all welcome, and all help me decide what to build next. Use the same forms.
